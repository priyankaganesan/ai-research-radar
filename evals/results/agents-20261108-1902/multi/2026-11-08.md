## 1. Harness-S: Learning from Sibling Harnesses for Generalizable Agent Training

**Top pick** · `2611.04277` · 2026-11-03 · [link](https://arxiv.org/abs/2611.04277)

The paper addresses the challenges of Locality, Complementarity, and Nonstationarity in harness evolution where variants repair different failures with changing utility as policies learn. It introduces Harness-S, which uses Directional Harness Evolution to create a fixed pool of sibling harnesses that selectively rescue base execution failures and transfer capabilities into a single policy via Complementary Harness Rescue Training. ## 5. WeLM-Image: A Unified Image Generation Model towards Visual Intelligence

**Top pick** · `2611.07392` · 2026-11-05 · [link](https://arxiv.org/abs/2611.07392)

WeLM-Image is a unified image foundation model designed for single-GPU deployment that integrates multimodal understanding into text-to-image generation, instruction-guided editing, and multi-reference synthesis by processing inputs as one interleaved sequence [2611.07392]. The architecture employs a Mixture-of-Transformers backbone with Mixture-of-Experts modules to limit optimization interference while balancing semantic coverage and editing tasks through a specialized data engine and noise-aware distillation [2611.07392]. This approach enables the model to rank first among evaluated open-source models on multiple benchmarks and achieve rapid generation of 1024×1024 images in under 5 seconds using few-step distillation [2611.07392].
