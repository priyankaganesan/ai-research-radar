## 1. From Pixels to Actions - Towards Native Vision-Language-Action Policies

**Top pick** · `2611.06918` · 2026-11-04 · [link](https://arxiv.org/abs/2611.06918)

Existing vision-language-action models typically compress perception through fixed visual encoders before action reasoning begins, potentially losing critical local geometric signals needed for manipulation. The key idea is NEO-VLA, a structurally encoder-free framework where images are tokenized by lightweight patch convolutions and evolve jointly with language throughout the backbone to allow action experts to access representations at different depths. This approach demonstrates that native architectures outperform encoder-based counterparts in robustness and control, revealing that action-critical signals often peak before the final visual representation [2611.06918].

## 2. Tools Need Not Speak in Text: Latent Context Compression for Agents

**Top pick** · `2611.06500` · 2026-11-04 · [link](https://arxiv.org/abs/2611.06500)

LLM agents suffer from high context overhead and diluted attention when appending raw, noisy tool outputs as discrete text tokens over multi-step interactions [2611.06500]. The key idea is Coca-Cola, a continuous latent context compression model that embeds compressed tool observations directly into the agent's input embedding space while using Action-Preserving Training to ensure decision-critical information is retained [2611.06500]. Experiments demonstrate that this approach reduces token consumption by 70.01%-89.24% and runtime by 24.45%-55.97% while consistently improving task performance [2611.06500].

## 3. EvoMemState: Evolving Memory State for Personal Agents

**Top pick** · `2611.03743` · 2026-11-02 · [link](https://arxiv.org/abs/2611.03743)

Existing long-term memory systems for LLM agents often treat facts independently, potentially overlooking how new information updates or conflicts with earlier entries while leaving their applicability implicit [2611.03743]. EvoMemState addresses this by introducing a state-centric framework that augments persistent facts with Relational States to track validity and evolution, alongside a Reasoning State generated via reinforcement learning to determine fact application for specific requests [2611.03743]. Extensive experiments on dialogue and memory-use benchmarks demonstrate that this approach yields consistent improvements in retrieval completeness and memory-grounded response accuracy compared to existing systems [2611.03743].

## 5. Turns Matter: Advancing Streaming Video RL via Turn-Level Credit

**Top pick** · `2611.06728` · 2026-11-04 · [link](https://arxiv.org/abs/2611.06728)

Existing streaming video RL approaches using trajectory-level advantages often reinforce redundant replies or discourage useful follow-ups due to shared credit across turns [2611.06728]. TurnWise addresses this by introducing a turn-level GRPO framework that assigns credit individually to each decision using silence-completed prefix scoring and equal-weighted policy optimization [2611.06728]. This method improves streaming policy learning and outperforms prior RL approaches without requiring a learned critic or additional rollouts [2611.06728].

## 6. On the Opportunities and Challenges of Prefill-to-Autoregressive Cross-Model Transfer

**Top pick** · `2611.06976` · 2026-11-04 · [link](https://arxiv.org/abs/2611.06976)

The paper addresses the challenge of verifying whether prefill-to-autoregressive cross-model transfer (PACT) systems genuinely benefit from communication or merely exploit uninformative signals through parameter-efficient adaptation. ## 7. VFlash: Fast, Accurate Visual Planning via Flash Primitive Decoding

**Early buzz** · `2611.08449` · 2026-11-05 · [link](https://arxiv.org/abs/2611.08449)

Autoregressive vision-language models are costly because they generate visual plans coordinate by coordinate, making richer spatial predictions increasingly expensive [2611.08449]. VFlash addresses this by exploiting the known structure of visual primitives to predict their coordinates jointly using a lightweight drafter that generates an entire primitive in one forward pass [2611.08449]. This approach reduces prediction errors relative to autoregressive decoding and achieves approximately 25x faster generation while improving world action model success rates on robot trajectory tasks [2611.08449].
